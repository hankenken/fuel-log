FUEL LOG Ver.0.2
GitHubで新規公開リポジトリを作り、このZIP内のファイルをルートにアップロード。Settings > Pages > Deploy from a branch > main / root > Save。表示されたHTTPS URLをSafariで開く。共有メニューからホーム画面に追加（端末により表示は異なる）。
既存5件を取り込むボタンで旧Excelの記録を登録。GPT指示をコピーし、ChatGPTに写真とともに送信。生成リンクをSafariで開くかJSONを貼り付け、確認・距離入力後保存。リンク内には購入情報が含まれるため共有しない。公開リポジトリに個人の購入データを置きたくない場合はseed.jsを const seed = []; に変更し、旧Excelをアプリ内から取り込む。公開前に必ず実施してください。
Excel出力は元台帳と同一書式ではなくデータ一覧。CSV/JSONも利用可能。ブラウザ保存は端末別、消去で失われる可能性があるのでJSONバックアップ推奨。燃費は前回満タン・途中給油なしを確認して選択した場合のみ算出。Excel入出力には外部JSライブラリへの通信が必要。APIキー不要。ブラウザ実機動作未検証。
